

\# Student Performance Prediction



A machine learning project built using Python,

Scikit-learn, and Streamlit.



\## Project Overview

This project demonstrates how machine learning

can classify student exam performance as Pass

or Fail using student background information.



\## Technologies Used

\- Python

\- Pandas

\- Scikit-learn

\- Matplotlib

\- Seaborn

\- Jupyter Notebook

\- Streamlit



\## Machine Learning Model

Selected Model: Balanced Logistic Regression



The model was selected based on cross-validation

performance for identifying failing students.



\## Features

\- Interactive student information form

\- Pass/Fail prediction

\- Model class scores

\- Simple Streamlit interface



\## How to Run

1\. Install dependencies:

&#x20;  pip install -r requirements.txt



2\. Start the application:

&#x20;  streamlit run app.py



\## Disclaimer

This is an educational demonstration.

Predictions are not reliable enough for real

student assessment or academic decisions.
